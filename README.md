# Student Grade Calculator

A beginner-friendly C project that calculates a student's grade based on their marks.

## Features

- Takes student name as input
- Accepts marks between 0 and 100
- Calculates grade using if-else conditions

## Technologies Used

- C
- GCC
- Git
- GitHub
- Kali Linux

## How to Run

Compile:

```bash
gcc main.c -o grade
```

Run:

```bash
./grade
```
